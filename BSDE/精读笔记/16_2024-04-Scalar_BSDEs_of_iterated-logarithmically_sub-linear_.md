## 核心结果

> **定理 2.2（逐字原文）**：Let 𝑛 ≥ 2, 𝜆 > 1/2 and the generator 𝑔 satisfy assumptions (H1), (H2)ⁿ_𝜆 and (H3). Then BSDE(𝜉, 𝑔) admits a solution (𝑌ₜ, 𝑍ₜ)_{𝑡∈[0,𝑇]} such that (𝑌, 𝑍) ∈ 𝕊ₚ × 𝕄ₚ with each 𝑝 ∈ (0, 1), and 𝑌 belongs to class (D). And, there exists a constant 𝐶 > 0 depending only on (𝛽, 𝛾, 𝑛, 𝜆, 𝑇) such that
> |𝑌ₜ| ≤ |𝑌ₜ| + ∫₀ᵗ 𝑓ₛ d𝑠 ≤ 𝐶 E[|𝜉| + ∫₀ᵀ 𝑓ₛ d𝑠 | 𝔽ₜ] + 𝐶, 𝑡 ∈ [0,𝑇]. (2.1)
> Moreover, if assumptions (H4) and (H5)ⁿ_𝜆 also hold for the generator 𝑔, then the solution (𝑌, 𝑍) with 𝑌 being of class (D) is unique.
>
> *通俗解释*：生成元关于 𝑧 按「迭代对数次线性」增长即可得可积解；再加单调性与迭代对数一致连续则解唯一。（(2.1) 中首项 |𝑌ₜ| ≤ |𝑌ₜ|+… 疑为排印/提取冗余，[UNCERTAIN: 原文如此，疑似应为 |𝑌ₜ|+∫₀ᵗ𝑓ₛd𝑠 的整体估计]）

> **命题 2.4（逐字原文，比较定理）**：Let 𝑛 ≥ 2, 𝜆 > 1/2, 𝜉 and 𝜉′ be two terminal conditions, 𝑔 and 𝑔′ be two generators, and (𝑌ₜ, 𝑍ₜ) and (𝑌′ₜ, 𝑍′ₜ) be a solution of BSDE(𝜉, 𝑔) and BSDE(𝜉′, 𝑔′), respectively. Suppose that 𝑔 (resp. 𝑔′) satisfies assumptions (H4) and (H5)ⁿ_𝜆 and (𝑌 − 𝑌′)+ is of class (D). If 𝜉 ≤ 𝜉′ and for each 𝑡 ∈ [0,𝑇], 𝟏_{𝑌ₜ>𝑌′ₜ}(𝑔(𝑡,𝑌′ₜ,𝑍′ₜ) − 𝑔′(𝑡,𝑌′ₜ,𝑍′ₜ)) ≤ 0 (resp. 𝟏_{𝑌ₜ>𝑌′ₜ}(𝑔(𝑡,𝑌ₜ,𝑍ₜ) − 𝑔′(𝑡,𝑌ₜ,𝑍ₜ)) ≤ 0), then we have 𝑌ₜ ≤ 𝑌′ₜ for each 𝑡 ∈ [0,𝑇].
>
> *通俗解释*：广义单调 + 迭代对数一致连续下，可积解满足比较定理，从而唯一性。

> **命题 2.8（逐字原文，星形风险测度）**：对 𝑔(𝑧) = −𝑐|𝑧|/Φⁿ_𝜆(|𝑧|) 定义的 𝜌ᵍₜ(𝜉):=𝑌ᵉₜ 满足 (i) 规范化、(ii) 单调性、(iii) 平移不变性、(iv) 一致性、(v) 星形性 𝜌ᵍₜ(𝜃𝜉) ≥ 𝜃𝜌ᵍₜ(𝜉)，𝜃>1。
>
> *通俗解释*：所得解映射构成 𝐿¹ 上的动态星形风险测度。

**关键假设**（§2 原文）：

- (H1) dP×d𝑡-a.e.，𝑔(𝜔,𝑡,·,·) 连续。
- (H2)ⁿ_𝜆：sgn(𝑦)𝑔(𝜔,𝑡,𝑦,𝑧) ≤ 𝑓ₜ(𝜔) + 𝛽|𝑦| + 𝛾|𝑧|/Φⁿ_𝜆(|𝑧|)（单边线性 + 迭代对数次线性增长）。
- (H3)：|𝑔| ≤ 𝑓ₜ + ℎ(|𝑦|) + 𝑐|𝑧|²（ℎ∈𝐒，一般二次增长）。
- (H4)：扩展单调性，存在凹函数 𝜌∈𝐒，∫₀₊ d𝑢/𝜌(𝑢)=+∞（Osgood 型），𝑔(𝑦₁)−𝑔(𝑦₂) ≤ 𝜌(𝑦₁−𝑦₂)。
- (H5)ⁿ_𝜆：|𝑔(𝑦,𝑧₁)−𝑔(𝑦,𝑧₂)| ≤ 𝜅(|𝑧₁−𝑧₂|/Φⁿ_𝜆(|𝑧₁−𝑧₂|))，𝜅 线性增长。
- 旧条件 (H2S)𝛼、 (H5S)𝛼：次线性 𝛾|𝑧|^𝛼 与拟 Hölder 连续；文中证明 (H2S)𝛼⇒(H2)ⁿ_𝜆、(H5S)𝛼⇒(H5)ⁿ_𝜆（Remark 2.5）。

## 证明骨架

- **武器库**：检验函数法（源自 [13] Fan–Hu）、局部化技巧（源自 [6] Briand–Hu）、Itô–Tanaka 公式、先验估计、比较定理（[18] 的 Theorem 2.1 起关键作用）、Osgood/凹单调 (H4)、初等不等式。
- **核心技巧**：构造检验函数 𝜑(𝑠,𝑥)=[𝑘+𝑥](1−(ln⁽ⁿ⁾(𝑘+𝑥))^{1−2𝜆})·exp(2(𝛽+2𝛾²/(2𝜆−1))𝑠)，使二次项被吸收，即 −𝛽𝜑ₓ𝑥 − 𝜑ₓ·𝛾|𝑧|/Φ + ½𝜑ₓₓ|𝑧|² + 𝜑ₛ ≥ 0（(3.24)），从而用 Itô–Tanaka 公式对 |𝑌|+∫𝑓 得先验界。
- **证明链**：命题 3.1（对两次可微 𝜓 的初等不等式）→ 命题 3.2（关键不等式 2𝑥𝑦/Φⁿ_{𝜆,𝑘}(𝑦) ≤ 𝑝𝑥²/(Φⁿ_{𝜆,𝑘}(𝑥))² + 𝑦²，[UNCERTAIN: 原文分子被提取丢失，按结构复原]）→ 命题 3.4（检验函数存在）→ 命题 3.5（先验界 (3.25)）→ 用 [6] 的局部化 + [21] Theorem 2.1 的构造得存在性；唯一性经命题 2.4 比较定理。

## 与其他文献的关联

- **Pardoux–Peng [1] (1990)**：引入非线性 BSDE，Lipschitz + 平方可积参数；本文为「仅可积参数」方向的延续。
- **Briand–Delyon–Hu–Pardoux–Stoica [16] (2003)**：𝐿ᵖ 解、次线性增长 (H2S)𝛼；本文 (H2)⁰₁ 恰为其 (H1)，并说明 (H2S)𝛼⇒(H2)ⁿ_𝜆。
- **Fan [18] (2016)**：一般假设下纯量 BSDE 的 𝐿¹ 解；其 Theorem 2.1 在本文比较/唯一性证明中起关键作用。
- **Fan–Hu–Tang [21] (2023, 前作)**：对数 sub-linear（即 𝑛=1, 𝜆>1/2）情形；本文给出 𝑛≥2 的「越来越弱」条件序列，且唯一性不再要求 𝑍∈𝕄ₚ（[16–18] 要求），故严格改进 [21, Theorem 2.1]。
- **Hu–Tang [10] (2018)**：说明 (H2)ⁿ_𝜆 在 𝑛=1、𝜆=0 时不足以保证存在性；(H2)ⁿ_𝜆 对 𝜆∈(0,1/2] 是否充分仍为公开问题（Remark 2.3）。
- **应用**：Peng [15] 的 𝑔-期望推广到 𝐿¹ 空间；Castagnoli 等 [22] 的星形风险测度。
